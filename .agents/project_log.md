## ⚙️ Core Technical Rules & Specifications

1. **Voice Standard**: Must use `en-GB-Chirp3-HD-Aoede` (Google Cloud TTS) with `volumeGainDb: 4.0` and FFmpeg `loudnorm=I=-14:LRA=7:TP=-1.5` so all audio is evenly balanced to broadcast standards.
2. **Audio Mixing**: Individual scenes only contain voice + transition SFX. Master BGM (`clean bgm2.mp3` = 3,127s) is mixed exclusively in `assembleMasterVideo` at `0.08` volume with random start offset, 1.5s fade-in, and 2.5s fade-out.
3. **Card vs Full-Screen Visuals**: 
   - Low-res GIFs scale into styled bounding cards (`maxW = 1420, maxH = 780`).
   - Screen Studio Cursor clips (`ScreenStudioCursorAnimator`) always render full-screen 1080p without bounding card borders.
   - Author diagrams scale to `maxW = 1680, maxH = 880` (near full-page). All SVGs rasterized to PNG with Sharp.
4. **Desktop Captures**: Dynamic live DOM layout scan with Apple Retina `deviceScaleFactor: 2.0` and hidden sticky headers to preserve clean macOS navigation without button wrapping.
5. **Anti-Repetition**: `gif_history_db.json` persists past used GIFs; 10+ Screen Studio flight archetypes with Bézier curvature and randomized 1.25x–1.55x zoom ensure infinite visual variety.
6. **Thumbnails**: Use Vertex AI Nano Banana 2 (`gemini-2.5-flash-image`) with `Assets/Character Reference.png` multimodal prompt; focus on tangible physical materials (steel, cardboard, solid 3D architectural letters) and strictly avoid generic "futuristic/sci-fi" keywords.
